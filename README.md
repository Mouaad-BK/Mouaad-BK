### 🍽 Restaurant Recommendation & Sentiment Analysis System

Development of an intelligent restaurant recommendation and sentiment analysis system based on Yelp reviews.

**Key components**

* Sentiment classification of customer reviews (positive / negative)
* End-to-end NLP pipeline including preprocessing, tokenization, stopword removal, lemmatization and TF-IDF vectorization
* Training and evaluation of multiple machine learning models
* Restaurant recommendation engine based on user preferences and review analysis
* Comparative analysis of model performance using multiple evaluation metrics

**Technologies**

Python • Scikit-Learn • NLP • Pandas • TF-IDF • Machine Learning

---

### 🌦 Weather Data ETL Pipeline

Development of an ETL pipeline for collecting, processing, and analyzing weather data.

**Key components**

* Data collection from OpenWeather API and CSV datasets
* Data cleaning and transformation pipeline
* Storage of processed data in a cloud-hosted PostgreSQL database
* Automated pipeline orchestration with Apache Airflow running in Docker
* Interactive data visualization dashboard built with Power BI

**Technologies**

Python • PostgreSQL • Apache Airflow • Docker • Power BI • Cloud

## 📌 Featured Projects

### ☀️ Solar Energy Forecasting Platform

**MLOps**

Development of an end-to-end MLOps platform for solar energy production forecasting.

**Key components**

* Development of an hourly ETL pipeline to collect, transform, and load solar production, irradiance, and weather data from multiple API sources
* Implementation of a data lake using AWS S3 and a data warehouse using Snowflake for data storage and analytics
* Development of a distributed preprocessing pipeline with PySpark for data cleaning, transformation, and aggregation
* Advanced feature engineering with more than 30 features including weather-derived variables, temporal features, and metadata
* Training and optimization of an XGBoost model achieving approximately 98% prediction performance
* Experiment tracking and model selection using MLflow
* Deployment of a FastAPI prediction service for real-time inference
* End-to-end orchestration and automation of data, machine learning, and serving pipelines using Apache Airflow and Docker

**Technologies**

Python • PySpark • XGBoost • MLflow • FastAPI • Apache Airflow • Docker • AWS S3 • Snowflake • dbt • SQL
